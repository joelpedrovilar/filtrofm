Política de Privacidade

A FILTRO FM respeita a privacidade dos seus visitantes e procura tratar qualquer informação pessoal de forma transparente, responsável e segura.

1. Responsável pelo tratamento

```

O responsável pelo tratamento dos dados pessoais relacionados com este website é a FILTRO FM.

Para questões relacionadas com privacidade e proteção de dados:

radiofiltrofm@gmail.com

```

2. Que dados podem ser tratados

```

A utilização normal do website da FILTRO FM não exige a criação de uma conta nem o fornecimento de dados pessoais para ouvir a rádio.

Poderão, contudo, ser tratados determinados dados técnicos necessários ao funcionamento, segurança e manutenção dos serviços, tais como:

  • endereço IP;
  • data e hora de acesso;
  • tipo de navegador e dispositivo;
  • informação técnica relativa ao acesso ao website;
  • informação necessária para diagnóstico de problemas técnicos ou de segurança.
```

3. Finalidades do tratamento

```

Os dados técnicos poderão ser tratados para:

  • disponibilizar e manter o website;
  • garantir a segurança e estabilidade do serviço;
  • detetar e prevenir utilização abusiva ou incidentes de segurança;
  • diagnosticar problemas técnicos;
  • cumprir obrigações legais aplicáveis.
```

4. Base legal

```

O tratamento de dados técnicos necessários ao funcionamento e segurança do website poderá basear-se no interesse legítimo do responsável pelo tratamento e, quando aplicável, no cumprimento de obrigações legais.

Sempre que um tratamento depender de consentimento, este será solicitado de forma adequada antes do tratamento correspondente.

```

5. Cookies

```

A FILTRO FM procura manter o website simples e evitar a utilização de cookies não essenciais.

Atualmente, não pretendemos utilizar cookies destinados a publicidade personalizada ou rastreamento para fins de marketing.

Poderão existir tecnologias ou mecanismos técnicos estritamente necessários ao funcionamento, segurança e disponibilização dos serviços.

Se forem posteriormente adicionados serviços de análise, publicidade, marketing ou outras tecnologias que exijam consentimento, esta política será atualizada e será implementado o mecanismo de consentimento adequado.
```

6. Alojamento e serviços técnicos

```

O website da FILTRO FM é disponibilizado através de serviços de infraestrutura e alojamento web utilizados para publicar e proteger o website.

A rádio e o respetivo streaming são disponibilizados através de um serviço externo de transmissão de rádio.

Esses prestadores poderão tratar determinados dados técnicos necessários à prestação, segurança e funcionamento dos respetivos serviços.

```

7. Conservação dos dados

```

Os dados pessoais serão conservados apenas durante o período necessário às finalidades para as quais foram recolhidos ou durante o período exigido por lei, quando aplicável.

Os períodos concretos de conservação podem variar de acordo com a natureza dos dados e do serviço técnico envolvido.

```

8. Direitos dos titulares dos dados

```

Nos termos do RGPD, os titulares dos dados podem, quando aplicável, exercer direitos relativamente aos seus dados pessoais, incluindo:

  • direito de acesso;
  • direito de retificação;
  • direito ao apagamento;
  • direito à limitação do tratamento;
  • direito de oposição;
  • direito à portabilidade dos dados, quando aplicável;
  • direito de retirar o consentimento quando o tratamento se baseie em consentimento.

Para exercer estes direitos, contacte:

radiofiltrofm@gmail.com

```

9. Reclamação

```

Caso considere que os seus direitos de proteção de dados não foram respeitados, o titular pode apresentar uma reclamação junto da autoridade de controlo competente.

Em Portugal, a autoridade de controlo é a Comissão Nacional de Proteção de Dados (CNPD) .

```

10. Alterações a esta política

```

Esta Política de Privacidade poderá ser atualizada sempre que ocorram alterações relevantes no funcionamento do website, nos serviços utilizados ou nas obrigações legais aplicáveis.

A versão mais recente estará sempre disponível nesta página.

```
